# IoT-Based Voice-Enabled Smart Home Automation

An IoT-based smart home automation system designed to control home appliances using voice commands, web-based control, and automatic sensing.

## 📌 Project Overview

This project uses an ESP32-based system to provide smart and convenient control of home appliances. The system supports automatic and manual control modes and integrates sensors for monitoring and automation.

## 🛠️ Technologies & Components

- ESP32
- DHT11 Temperature & Humidity Sensor
- LDR (Light Dependent Resistor)
- 2-Channel Relay Module
- Fan
- Light
- Wi-Fi
- Bluetooth
- Arduino IDE
- Web Server

## ⚙️ Key Features

- Voice-enabled appliance control
- Web-based control interface
- Automatic and manual operating modes
- Temperature and humidity monitoring
- Light intensity-based automation
- Wireless control using ESP32
- Low-cost and scalable smart home solution
